# Recorded sounds

Every file in this folder is released under Creative Commons Zero (CC0 1.0, public domain
dedication): free for commercial use, no attribution required. Sources are listed anyway. Files
were trimmed and re-encoded to mono OGG. The licenses below are the ones stated by each source
repository; check the original pages before shipping if you need certainty.

| Files | Source | Stated license |
|---|---|---|
| `crowd_loop`, `panic_loop`, `roar_*`, `cheer_*`, `scream_*`, `ooh`, `chant_*`, `surge` | github.com/joepio/godot-crowd-sound (`addons/crowd_sound/samples`), built from Freesound recordings by zedkah, D.jones, felix.blume, itmightgetloud, Sandermotions, magician5, JohnsonBrandEditing, oozlum, craigsmith and IENBA | CC0 (its CREDITS.md lists each Freesound recording) |
| `moo`, `baa`, `trot`, `oink`, `cluck` | github.com/DJWoodZ/Animal-Sounds (`src/sounds`), from Freesound recordings by josephsardin, sandeepkurissery, Oscar de Ávila, JarredGibb and Rudmer_Rotteveel | CC0 1.0 |
| `bark_*`, `beast_*`, `howl`, `explosion`, `bang_*`, `crash_*`, `glass`, `hit_*`, `splash_*`, `spring`, `gong`, `bell`, `rain_loop` | github.com/lavenderdotpet/CC0-Public-Domain-Sounds (CC0 SFX packs) | CC0 1.0 |
| `ui_*` | Kenney "Interface Sounds" (kenney.nl), via github.com/Calinou/kenney-interface-sounds | CC0 1.0 |
| `jingle_win`, `jingle_lose` | Kenney "Music Jingles" (kenney.nl) | CC0 1.0 |

| `voice/male_*`, `voice/female_*`, `voice/pig_*` (ouches, gasps, falls, jumps) | Warfork player voices by Team Forbidden, via github.com/lavenderdotpet/CC0-Public-Domain-Sounds (`warfork-cc0`, whose notice states CC0 1.0) | CC0 1.0 |
| `voice/ann_*` (the announcer: go, time over, medic, mission completed/failed, game over...) | Kenney "Voiceover Pack" (kenney.nl), voices by Jeffrey M. Smith (male) and the pack's female voice actor, via the same collection | CC0 1.0 |
| `voice/cr_*` (cute animals, grunts, munching, snoring, zombie groans, aliens, bugs, howls, burps, coughs, mumbles) | CC0 creature SFX packs in github.com/lavenderdotpet/CC0-Public-Domain-Sounds | CC0 1.0 |

The game still works without these files: every effect has a synthesized fallback.
